# CuraCare – Personal Health & First Aid Assistant

## Project Name
**CuraCare**  
Personal Health & First Aid Assistant Application

---

## Problem Statement
-
ในชีวิตประจำวัน ผู้คนจำนวนมากประสบปัญหาในการเข้าถึงข้อมูลด้านสุขภาพที่ถูกต้องและเข้าใจง่าย ไม่ว่าจะเป็นการค้นหาอาการเจ็บป่วยเบื้องต้น การจดจำโรคประจำตัว ข้อมูลยาที่ต้องรับประทาน รวมถึงการขาดความรู้ด้านการปฐมพยาบาลในสถานการณ์ฉุกเฉิน ส่งผลให้เกิดความเสี่ยงต่อสุขภาพและความปลอดภัย
แอพพลิเคชัน Docterathome จึงถูกพัฒนาขึ้นเพื่อช่วยให้ผู้ใช้สามารถเข้าถึงข้อมูลโรค อาการ การดูแลรักษาเบื้องต้น บันทึกข้อมูลสุขภาพส่วนบุคคล และเรียนรู้วิธีการปฐมพยาบาลได้อย่างสะดวกและรวดเร็ว
---

## Target Users
-
-ผู้ที่มีโรคประจำตัว
-ผู้ต้องการความรู้เรื่องสุขภาพ

4).บันทึกโรคประจำตัว

## Non-Functional Requirements
- **Usability**: แอพต้องออกแบบให้ใช้งานง่าย ตัวอักษรชัดเจน เหมาะสำหรับทุกช่วงวัย รวมถึงผู้สูงอายุ 
- **Performance**: การค้นหาโรค อาการ และการเปิดข้อมูลต้องใช้เวลาไม่นาน และตอบสนองได้อย่างรวดเร็ว  
- **Reliability**: ข้อมูลโรค ยา และการปฐมพยาบาลต้องมีความถูกต้องและอ้างอิงจากแหล่งข้อมูลที่น่าเชื่อถือ  
- **Security**: ข้อมูลสุขภาพส่วนบุคคลของผู้ใช้ต้องถูกจัดเก็บอย่างปลอดภัย และไม่ถูกเข้าถึงโดยไม่ได้รับอนุญาต 
- **Scalability**: ระบบต้องสามารถใช้งานได้ตลอดเวลา และข้อมูลสำคัญควรเข้าถึงได้แม้ไม่มีอินเทอร์เน็ต

# CuraCare – Personal Health & First Aid Assistant

## Project Name
**CuraCare**  
Personal Health & First Aid Assistant Application


---

## Problem Statement

ในชีวิตประจำวัน ผู้คนจำนวนมากประสบปัญหาในการเข้าถึงข้อมูลด้านสุขภาพที่ถูกต้องและเข้าใจง่าย  
ไม่ว่าจะเป็นการค้นหาอาการเจ็บป่วยเบื้องต้น การจดจำโรคประจำตัว ข้อมูลยาที่ต้องรับประทาน  
รวมถึงการขาดความรู้ด้านการปฐมพยาบาลในสถานการณ์ฉุกเฉิน ซึ่งส่งผลให้เกิดความเสี่ยงต่อสุขภาพและความปลอดภัย

แอปพลิเคชัน **CuraCare** จึงถูกพัฒนาขึ้นเพื่อช่วยให้ผู้ใช้สามารถเข้าถึงข้อมูลโรคและอาการ  
การดูแลรักษาเบื้องต้น บันทึกข้อมูลสุขภาพส่วนบุคคล  
และเรียนรู้วิธีการปฐมพยาบาลได้อย่างสะดวก รวดเร็ว และเข้าใจง่าย


---

## Target Users

- ผู้ที่มีโรคประจำตัวและต้องการติดตามข้อมูลสุขภาพ  
- ผู้ที่ต้องการความรู้ด้านสุขภาพและการดูแลตนเองเบื้องต้น  
- บุคคลทั่วไปที่ต้องการคู่มือปฐมพยาบาลในสถานการณ์ฉุกเฉิน  


---

## MVP Features

1. ค้นหาข้อมูลอาการและโรค  
2. บันทึกโรคและยาประจำตัว 
3. คู่มือการปฐมพยาบาลเบื้องต้น 
4. แจ้งเตือนแผนกิจวัตรประจำวันตามโรค
5. ปฎิทินนัดหมาย

---

## Nice-to-Have Features (Future Work)

1. สมัครสมาชิก/เข้าสู่ระบบ 
2. แชทระหว่างหมอกับผู้ป่วย 
3. ตั้งค่าโปรไฟล์ 
4. โหมดมืดโหมดสว่าง 
5. ฟอรั่มหมอให้ความรู้เกี่ยวกับโรค 
6. บันทึกกิจวัตร

---

## Non-Functional Requirements

- **Usability**  
  แอปต้องออกแบบให้ใช้งานง่าย ตัวอักษรชัดเจน  
  เหมาะสำหรับทุกช่วงวัย รวมถึงผู้สูงอายุ  

- **Performance**  
  การค้นหาโรค อาการ และการเปิดข้อมูลต้องตอบสนองได้อย่างรวดเร็ว  

- **Reliability**  
  ข้อมูลโรค ยา และการปฐมพยาบาลต้องมีความถูกต้อง  
  และอ้างอิงจากแหล่งข้อมูลที่น่าเชื่อถือ  

- **Security**  
  ข้อมูลสุขภาพส่วนบุคคลของผู้ใช้ต้องถูกจัดเก็บอย่างปลอดภัย  
  และไม่ถูกเข้าถึงโดยไม่ได้รับอนุญาต
